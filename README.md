# @kep4yk/rbac-jwt-core

Ядро системы управления доступом на основе ролей (RBAC) с использованием JWT-токенов. Модуль разработан для интеграции в микросервисную архитектуру научного портала и обеспечивает надежную проверку прав доступа, кэширование сессий и отзыв токенов.

## О проекте

Пакет предоставляет готовый инструментарий для аутентификации и авторизации запросов. Основной акцент сделан на безопасность, производительность и консистентность данных. Ролевая модель хранится в реляционной базе данных, а матрица доступа и черные списки токенов кэшируются в in-memory хранилище, что минимизирует нагрузку на основную БД при проверке каждого HTTP-запроса.

**Основные возможности:**

* Генерация и криптографическая проверка JWT-токенов.
* Декораторы/middleware для фреймворка Fastify.
* Кэширование ролей и прав доступа.
* Механизм принудительного отзыва токенов (Blacklist).
* Готовая схема базы данных (Prisma) с сидером базовых ролей.

## Архитектура и стек

Система спроектирована с учетом строгих стандартов разработки программного обеспечения и разделена на независимые слои (core, cache, db, http).

* **Язык:** TypeScript (Node.js)
* **Web-фреймворк:** Fastify
* **ORM:** Prisma
* **База данных:** Microsoft SQL Server 2022 (Developer Edition)
* **Кэширование:** Redis 7 (Alpine)
* **Инфраструктура:** Docker, Docker Compose

## Развертывание и установка

Для локальной разработки и интеграционного тестирования инфраструктура модуля контейнеризирована.

### 1. Поднятие инфраструктуры

```bash
docker compose up -d mssql-db redis-db
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

| Переменная     | Описание                        | Пример значения                                                          |
| -------------- | ------------------------------- | ------------------------------------------------------------------------ |
| `DATABASE_URL` | Строка подключения к SQL Server | `sqlserver://localhost:1433;database=master;user=sa;password=YourStrong!Passw0rd` |
| `REDIS_URL`    | URL для подключения к Redis     | `redis://localhost:6379`                                                 |
| `JWT_SECRET`   | Секретный ключ для подписи токенов | `super_secret_string`                                                 |

### 4. Инициализация базы данных

```bash
# Применение миграций
npx prisma db push

# Заполнение базовыми ролями (Admin, Researcher)
npm run prisma:seed
```

## Использование API

Пакет предоставляет единую точку входа (`index.ts`) для интеграции в основное приложение.

**Инициализация модуля при старте сервера:**

```typescript
import Fastify from 'fastify';
import { initRbacModule } from '@kep4yk/rbac-jwt-core';

const app = Fastify();

app.register(async function (app) {
  // Синхронизация БД ролей с кэшем Redis
  await initRbacModule();
});
```

**Защита маршрутов с помощью middleware:**

```typescript
import { verifyTokenHook } from '@kep4yk/rbac-jwt-core';

// Эндпоинт доступен только администраторам
app.get('/admin/panel', {
  preHandler: verifyTokenHook(['Admin'])
}, async (request, reply) => {
  return { message: 'Добро пожаловать в панель управления' };
});

// Эндпоинт доступен администраторам и научным сотрудникам
app.get('/research/data', {
  preHandler: verifyTokenHook(['Admin', 'Researcher'])
}, async (request, reply) => {
  return { data: 'Секретные научные данные' };
});
```
